5. Residential flow remains: Residential → select plot size → Materials & Quote Cart.
   Commercial flow remains: Commercial → the same Materials & Quote Cart.

7. The quote cart supports quantity/unit editing, removing items, customer details, delivery area, notes, and a structured quote request.
8. Keeps the approved main-site artwork, Home/Trucking/Media assets, and existing scene-transition integration.

HOW TO APPLY TO GITHUB / VERCEL
-------------------------------
1. Download and extract this ZIP.
2. Upload the ZIP contents to the ROOT of the existing WAYFORTH repository, replacing matching files only.
3. Keep your existing index.html, app.js, styles.css, and scenes-data.js. Do not delete them.
4. In Vercel, keep the Build Command set to: node patch-wayforth.js
5. Commit with the exact message above and wait for the deployment to finish.
6. Open Home → Build. Confirm the hero image has no artificial black side panels.
7. Click Residential, choose a plot size, then Explore Materials & Cart. Verify the six cards and cart.
8. Return to Build Options, click Commercial, and confirm it opens the same six-material selection/cart interface.
